# Victory Buzzer Music Choices

Generated by `tools/generate_more_victory_buzzer_music.py`.

All files are 4 kHz, unsigned 8-bit PCM, mono WAV files for the passive-buzzer
PCM player.

## Files

- `win_jolly_good_fellow_buzzer.wav` - about 12.64 s, congratulatory traditional tune
- `win_cancan_buzzer.wav` - about 8.22 s, fast Offenbach "Can-Can" style victory
- `win_saints_marching_buzzer.wav` - about 9.78 s, bright march tune
- `win_william_tell_gallop_buzzer.wav` - about 5.44 s, compact gallop/fanfare cue

## Usage

To test one option as the victory sound:

1. Copy the chosen WAV into `music/win`, or point the `WIN` track directory in
   `tools/generate_buzzer_pcm.py` to `music/win_choices`.
2. Make sure only the intended WAV is in that directory, because the generator
   uses the first audio file it finds.
3. Run `tools/generate_buzzer_pcm.py` to regenerate `buzzer_pcm_rom.mem` and
   `buzzer_pcm_rom.svh`.
