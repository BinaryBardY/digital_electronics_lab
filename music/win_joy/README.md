# Joy Victory Buzzer Music

Generated by `tools/generate_ode_to_joy_victory_sfx.py`.

- File: `win_joy_ode_to_joy_buzzer.wav`
- Format: 4 kHz, unsigned 8-bit PCM, mono
- Duration: about 13.13 s
- Melody basis: Beethoven's public-domain "Ode to Joy" theme, trimmed and lifted
  into a passive-buzzer-friendly register

Source/license notes:

- Wikimedia Commons lists `Ode to Joy.ogg` as public domain and notes that its
  source was a public-domain MIDI from Mutopia:
  https://commons.wikimedia.org/wiki/File:Ode_to_Joy.ogg
- Wikisource marks Beethoven's "Ode to Joy" work as public domain worldwide:
  https://wikisource.org/wiki/Ode_to_Joy_(Beethoven)

To use this as the project victory sound, point the `WIN` track directory in
`tools/generate_buzzer_pcm.py` to `music/win_joy`, then regenerate the PCM ROM.
