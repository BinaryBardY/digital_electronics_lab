# 《野火升腾_Mini开发板》 完整引脚分配与功能映射表

> **说明**：本文档基于《[野火]升腾_Mini开发板硬件规格书V1.1》，汇总了核心板与底板上所有外设的 FPGA 物理引脚绑定信息，并详细补充了各个引脚的具体功能对应关系，方便在编写约束文件（XDC）时直接查阅。

---

## 一、 核心板板载资源 (Core Board Peripherals)

### 1. 50MHz 系统时钟 (50MHz Oscillator)

提供 FPGA 系统主时钟输入。

| 引脚功能描述         | 引脚名 (Net Name) | FPGA 绑定引脚 |
|:-------------- |:-------------- |:--------- |
| **50MHz 时钟输入** | `FPGA_CLK`     | **W19**   |

### 2. SPI FLASH (W25Q128 128Mbit)

用于固化 FPGA 程序，实现掉电不丢失。

| 引脚功能描述         | 引脚名 (Net Name) | FPGA 绑定引脚 |
|:-------------- |:-------------- |:--------- |
| **片选信号 (CS)**  | `QSPI_CS`      | **T10**   |
| **时钟信号 (CLK)** | `QSPI_CLK`     | **L12**   |
| **数据 IO 0**    | `QSPI_IO0`     | **P22**   |
| **数据 IO 1**    | `QSPI_IO1`     | **R22**   |
| **数据 IO 2**    | `QSPI_IO2`     | **P21**   |
| **数据 IO 3**    | `QSPI_IO3`     | **R21**   |

## 二、 底板人机交互外设 (Baseboard HMI Peripherals)

### 1. 独立按键与复位按键 (Keys & Reset)

机械按键，按下为低电平（需注意防抖），用于系统控制。


| 引脚功能描述 | 引脚名 (Net Name) | FPGA 绑定引脚 | 对应底板丝印 |
| :--- | :--- | :--- | :--- |
| **FPGA 重新配置 (清空程序)** | `PROGRAM` | **N12** | `PROG` |
| **系统复位按键** | `RESET` | **Y19** | `RESET` |
| **用户按键 1** | `KEY1` | **R16** | `KEY1` |
| **用户按键 2** | `KEY2` | **P15** | `KEY2` |
| **用户按键 3** | `KEY3` | **T20** | `KEY3` |
| **用户按键 4** | `KEY4` | **Y18** | `KEY4` |

### 2. 用户指示灯 (LEDs)

单色蓝色 LED，输出高电平点亮。


| 引脚功能描述 | 引脚名 (Net Name) | FPGA 绑定引脚 | 对应底板丝印 |
| :--- | :--- | :--- | :--- |
| **用户指示灯 1** | `LED1` | **N20** | 靠近 KEY1 侧 |
| **用户指示灯 2** | `LED2` | **M20** | ... |
| **用户指示灯 3** | `LED3` | **N22** | ... |
| **用户指示灯 4** | `LED4` | **M22** | 靠近边缘侧 |

### 3. 无源蜂鸣器 (Passive Buzzer)

需要输入 PWM 波驱动发声，频率决定音调。


| 引脚功能描述 | 引脚名 (Net Name) | FPGA 绑定引脚 |
| :--- | :--- | :--- |
| **蜂鸣器 PWM 控制信号** | `BEEP` | **AA18** |

### 4. 6位8段数码管 (7-Segment Display)

## 三、 底板通信与多媒体接口 (Interfaces)

### 1. USB 转串口 (UART - CH340G)

Type-C 接口，用于与电脑进行串口通信。


| 引脚功能描述 | 引脚名 (Net Name) | FPGA 绑定引脚 | 说明 |
| :--- | :--- | :--- | :--- |
| **串口接收 (FPGA RX)** | `UART1_RX` | **W17** | 接收来自 PC 的数据 |
| **串口发送 (FPGA TX)** | `UART1_TX` | **V17** | 发送数据到 PC |

### 2. EEPROM (M24C64 - 64Kbit)

IIC 总线接口，存储小容量掉电不丢失数据。


| 引脚功能描述 | 引脚名 (Net Name) | FPGA 绑定引脚 |
| :--- | :--- | :--- |
| **IIC 时钟线** | `I2C_SCL` | **K19** |
| **IIC 数据线** | `I2C_SDA` | **J22** |

### 3. Micro SD 卡接口 (TF Card)

| 引脚功能描述 | 引脚名 (Net Name) | FPGA 绑定引脚 |
| :--- | :--- | :--- |
| **时钟** | `SD_CLK` | **M13** |
| **命令 / MOSI** | `SD_CMD` | **N14** |
| **卡插入检测** | `SD_CD` | **M16** |
| **数据位 0 / MISO** | `SD_D0` | **L13** |
| **数据位 1** | `SD_D1` | **M15** |
| **数据位 2** | `SD_D2` | **R19** |
| **数据位 3 / CS** | `SD_D3` | **N13** |

### 4. 摄像头接口 (Camera - OV5640/OV7725)

| **休眠控制** | `CAM_PDN` | **U17** | **复位控制** | `CAM_RST` | **AB18** |

### 8. TFT LCD 液晶屏接口 (RGB888)

40Pin FPC 接口，最大支持 24位色深 (RGB888)。

* **控制信号**：`LCD_CLK` (D19), `LCD_HS` (E19), `LCD_VS` (B18), `LCD_DE` (B17), `LCD_BL` 背光 (AA19)
* **红色通道 (R0-R7)**：J16, H22, J17, K17, K14, K13, J21, J20
* **绿色通道 (G0-G7)**：H19, J19, H15, J15, G18, G17, G13, H13
* **蓝色通道 (B0-B7)**：D22, E22, B22, C22, A19, A18, C20, D20
* **触摸屏 (CTP)**：SDA (J22), SCL (K19), RST (V18), INT (V19)

*(注：核心板的 DDR3 内存数据线和地址线因数量极大且一般由 MIG IP 核自动分配，此处未展开列出；若需调用直接使用官方 MIG 预设约束即可。)*
